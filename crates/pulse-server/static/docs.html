Pulse Analytics API

Self-hosted, multi-tenant web analytics with pageview tracking, custom events, real-time visitors, and a built-in dashboard.

Lightweight Tracking

761-byte script. Auto-tracks pageviews, SPA navigation, and respects Do Not Track.

Custom Events

Track any user action with arbitrary JSON metadata.

Real-time Visitors

See active visitors in the last 5 minutes, updated live.

Multi-tenant

One instance serves many projects. Scoped API keys for ingest vs. query.

Query API

Stats, timeseries, top pages, referrers, devices, geography, and events.

Built-in Dashboard

Login with a query API key to view analytics in a web UI.

Webhooks

Traffic spike alerts, zero-traffic warnings, and daily summary notifications.

Fast & Efficient

Rust + Redis buffering + daily rollup aggregation. Built on Axum + PostgreSQL.

Quick Start Integration

Get analytics running on your site in 5 steps:

Create a project

curl -X POST https://pulse.ayushojha.com/api/admin/projects \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN" \
  -d '{
    "name": "My Website",
    "domain": "mywebsite.com"
  }'

Save the returned id (project UUID).

Create an ingest API key

curl -X POST https://pulse.ayushojha.com/api/admin/projects/PROJECT_ID/keys \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN" \
  -d '{
    "name": "Ingest Key",
    "scopes": ["ingest"]
  }'

Save the returned key (e.g. pa_live_...). It's only shown once.

Create a query API key (for dashboard & API reads)

curl -X POST https://pulse.ayushojha.com/api/admin/projects/PROJECT_ID/keys \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN" \
  -d '{
    "name": "Dashboard Key",
    "scopes": ["query"]
  }'

Add the tracking script to your site

Place this before </body> in your HTML:

<script defer
  src="https://pulse.ayushojha.com/api/script.js"
  data-api="https://pulse.ayushojha.com"
  data-key="pa_live_YOUR_INGEST_KEY"></script>

That's it. Pageviews are tracked automatically, including SPA navigation.

View your analytics

Go to https://pulse.ayushojha.com/dashboard and log in with your query API key.

For ingest and query endpoints, the API key can also be passed as a query parameter: ?key=pa_live_...

Tracking Script

The simplest way to add analytics. Drop one script tag into your HTML:

<script defer
  src="https://pulse.ayushojha.com/api/script.js"
  data-api="https://pulse.ayushojha.com"
  data-key="pa_live_YOUR_INGEST_KEY"></script>

What it does automatically:

  • Tracks pageview on page load
  • Tracks SPA navigation (pushState / popstate)
  • Generates a privacy-friendly visitor ID (hashed from screen, timezone, language, UA)
  • Captures referrer, page title, screen size, and language
  • Respects navigator.doNotTrack (sends nothing if enabled)
  • Uses navigator.sendBeacon for reliable delivery
  • Only 761 bytes gzipped

Manual tracking from JavaScript

The script exposes a global pulse() function:

// Track a custom event
pulse('event', 'signup', { source: 'header_cta' });

// Identify a user
pulse('identify', { email: 'user@example.com', plan: 'pro' });

// Manual pageview (useful for SPAs with custom routing)
pulse('pageview');

Collect Endpoint

POST /api/collect Ingest Key

Unified tracking endpoint for pageviews, events, and identify calls. This is what the script tag and SDK use under the hood.

Request Envelope

{
  "type": "pageview",           // "pageview" | "event" | "identify"
  "payload": { ... },            // type-specific (see below)
  "visitor_id": "v_abc123",     // client-generated visitor identifier
  "timestamp": 1710300000000    // optional, milliseconds since epoch
}

Response 200 OK

{ "ok": true }

Pageview Payload

{
  "type": "pageview",
  "payload": {
    "path": "/products",
    "title": "Products Page",         // optional
    "referrer": "https://google.com",  // optional
    "screen": "1920x1080",            // optional
    "language": "en-US"               // optional
  },
  "visitor_id": "v_abc123"
}

Custom Events

{
  "type": "event",
  "payload": {
    "name": "add_to_cart",
    "data": {                          // optional, arbitrary JSON
      "sku": "ABC123",
      "price": 99.99
    },
    "path": "/checkout"               // optional, page where event occurred
  },
  "visitor_id": "v_abc123"
}

Identify Users

{
  "type": "identify",
  "payload": {
    "traits": {
      "email": "user@example.com",
      "plan": "pro",
      "company": "Acme Inc"
    }
  },
  "visitor_id": "v_abc123"
}

TypeScript SDK

Browser (Auto-tracking)

import { createPulse } from '@ayushojha/pulse-analytics';

const pulse = createPulse({
  apiKey: 'pa_live_YOUR_INGEST_KEY',
  apiUrl: 'https://pulse.ayushojha.com',
  autoTrack: true,     // auto-track pageviews + SPA nav
  respectDnt: true,    // honor Do Not Track
  debug: false
});

// Manual tracking
pulse.pageview('/checkout');
pulse.event('purchase', { amount: 99.99, currency: 'USD' });
pulse.identify({ userId: '123', email: 'user@example.com' });

// Query API (needs a query-scoped key)
const stats = await pulse.getStats({
  startAt: '2026-03-01',
  endAt: '2026-03-13'
});

Server-side (Node.js)

import { PulseServerClient } from '@ayushojha/pulse-analytics/server';

const pulse = new PulseServerClient({
  apiKey: 'pa_live_YOUR_KEY',
  apiUrl: 'https://pulse.ayushojha.com'
});

// Track server-side events
await pulse.trackEvent({
  visitorId: 'user123',
  eventName: 'api_call',
  data: { endpoint: '/checkout', latency_ms: 150 }
});

// Read analytics data
const stats = await pulse.getStats({
  startAt: '2026-03-01',
  endAt: '2026-03-13'
});

Webhook Signing

If you set a secret when creating a webhook, all payloads will include an X-Pulse-Signature header containing the HMAC-SHA256 signature of the request body. Verify it in your webhook handler:

const crypto = require('crypto');

function verifyWebhook(body, signature, secret) {
  const expected = crypto
    .createHmac('sha256', secret)
    .update(body)
    .digest('hex');
  return crypto.timingSafeEqual(
    Buffer.from(signature),
    Buffer.from(expected)
  );
}

Built-in Dashboard

Pulse includes a web dashboard at /dashboard. Log in with a query-scoped API key.

Dashboard Pages

  • Overview — Stats cards, timeseries chart
  • Pages — Top pages by views
  • Referrers — Traffic sources
  • Events — Custom event breakdown
  • Devices — Browser, OS, device type
  • Geography — Visitors by country
  • Realtime — Live active visitors

Access the dashboard at: https://pulse.ayushojha.com/dashboard
